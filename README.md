# QSW 2026 - Reproducible data analysis lab

This lab is part of the Quantitative Superresolution Microscopy Workshop 2026 ([QSW 2026](https://snyder.ucalgary.ca/labs/live-cell-imaging/learn-us/future-events/QSW-2026)) and focuses on the fundamentals of **reproducible data analysis**, combining a short lecture with hands-on exercises in R.

A central goal of this workshop is to highlight:
- Why reproducibility matters in data analysis
- How to structure projects so others (and your future self) can easily rerun them
- Practical tools (`renv`) to ensure consistent computational environments


## Repository Contents

This repository contains two projects designed to progressively build your understanding:

### **01_first_env — Getting Started with R & `renv`**

This project introduces:
- Basic R concepts and workflow
- Installing and using the `renv` package
- Initializing a reproducible R environment


### **02_qsw_pipeline — Image Analysis Pipeline**

This project builds on the basics and demonstrates:
- A more realistic data analysis workflow
- An example image analysis pipeline
- Structuring code for clarity and reproducibility
- Continued use of `renv` for dependency management
